# Morrow — React UI concept

A visual-only studio dashboard prototype built with React, Vite, and Lucide icons. The layout is responsive across desktop and mobile. Buttons and navigation are intentionally presentation-only; no account, project, search, or persistence behavior is connected.

## Run locally

1. Install Node.js 20 or later.
2. In this folder, run `npm install`.
3. Run `npm run dev` and open the local URL printed by Vite.

## Project files

- `src/App.jsx` — dashboard components and sample content
- `src/styles.css` — responsive art direction and styles
- `src/main.jsx` — React entry point
- `index.html` — Vite page shell

Google Fonts are used for the intended typography and fall back to system fonts if they are unavailable.
